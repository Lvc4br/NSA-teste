# NSA 2.0 — Protótipo React

Protótipo de uma proposta de evolução do NSA escolar, com foco em facilitar a experiência de estudantes e professores.

## Objetivo

Explorar uma interface escolar mais clara e organizada, com áreas de navegação para informações acadêmicas e rotinas do estudante.

## Conteúdo neste repositório

O arquivo `NSA-2.0-react (2).zip` contém o pacote do projeto enviado para este repositório.

**Importante:** no momento, o projeto está armazenado como arquivo ZIP. Para facilitar a revisão do código no GitHub, o próximo passo recomendado é extrair os arquivos-fonte para a raiz do repositório e manter fora do controle de versão pastas geradas, como `node_modules` e `dist`.

## Tecnologias

O pacote é identificado como um protótipo React. Consulte os arquivos do projeto para verificar a configuração e os comandos exatos de execução.

## Status

Protótipo em desenvolvimento; não representa um sistema oficial da ETEC ou do NSA.
